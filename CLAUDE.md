# Memory

## Preferences

- Automatically merge pull requests for this repository when they are conflict-free and all relevant checks pass, unless the user asks to review or hold a specific PR.
- Prefer delegating concrete, bounded subtasks to lower-cost subagents when useful, to conserve primary-model usage. Keep orchestration, integration, and final decisions with the primary agent.
